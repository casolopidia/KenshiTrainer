## 四、内部备忘（不写进工坊页面）

- Dust 共存实现：检测到 Dust 时跳过争议 dxgi 创建钩，改用 OGRE 内部纯读指针链
  找 swapchain（`_msWindows` / Root 单例 → D3D11RenderWindowHwnd vtable 校验 →
  +0x130 `mpSwapChain`），交现有 shadow vtable + 漂移重同步。全部偏移与验证记录见
  `docs\03-RE_Kenshi注入框架\Dust共存问题-移交文档.md`。
- 义肢修复根因：`setRobotLimbItem` 不碰背包，原版由四肢 GUI 自行移除；
  插件侧需自行 `removeItemDontDestroy_returnsItem` / `addItem` 做移出与退回。
  详见 `docs\03-RE_Kenshi注入框架\插件开发经验总结.md` 附录。
- 建筑放置绕过（BuildBypass）已知 bug 仍未修，工坊介绍已标注，保持现状。
- 护甲/十字弩生成的存档持久化风险（9/21 备忘）玩家仍无反馈，未修，继续观察。
