# 义肢编辑功能设计（医疗 Tab）

日期：2026-09-23，2026-10-27 修订。状态：已实现，待游戏内验证。

## 需求

实时编辑角色义肢。修改器支持直接安装和替换，无需先截肢；也保留截肢与恢复原生肢体功能。

## 数据来源

- 义肢不是 `ITEM` 类型物品，而是独立的 GameData 类型 **`LIMB_REPLACEMENT`**（这也是旧物品生成器永远列不出义肢的原因）。
- 运行库合并 DB（含 mod）枚举：`SafeGetDataOfType(&ou->gamedata, LIMB_REPLACEMENT, ...)`，按名字排序。
- 部位过滤优先识别本地化名称：英文 `left/right` 与 `arm/leg`，中文 `左/右` 与 `臂/腿`；再尝试 `limb type`、`limb`、`which limb` 的 0..3 值，对应 RobotLimbs::Limb 顺序：左臂/右臂/左腿/右腿。无法识别的项目不显示、不安装，并输出 `prosthetic compatibility unknown` 日志；不再默认向所有肢体开放。

## 调用路径（全部走 SafeXxx + SEH 包裹）

| 操作 | 游戏 API | 备注 |
|------|----------|------|
| 查状态 | `Character::getMedical()->getLimbState(limb)` |  |
| 截肢 | `MedicalSystem::amputate(limb, false, 0)` | `createSeveredItem=false`，不掉断肢物品 |
| 装义肢 | 先 `SafeCreatePlainItem` 造物品 → 放进角色背包 → `MedicalSystem::setRobotLimbItem(limb, item, false)` | 游戏自身肢体 GUI 也是这条路径 |
| 恢复 | 若义肢态先 `setRobotLimbItem(limb, NULL, false)` 摘除 → `RobotLimbs::setLimb(limb, LIMB_ORIGINAL, NULL)` → `HealthPartStatus::flesh = _maxHealth` + `updateDerivedHealths()` |  |

## UI

主面板「医疗」Tab：四肢各一行，显示状态（原生/断肢/义肢/粉碎），按钮：截肢、恢复原生（非原生态才显示）、义肢型号下拉 + 安装。下拉仅显示明确匹配该部位的型号，安装前再次校验；无匹配型号时给出提示。

## 风险与验证清单

- `setRobotLimbItem(NULL)` 摘除行为未验证（游戏可能销毁/掉落该物品），SEH 兜底。
- 模组义肢若名称及兼容性字段均无法识别，会安全拒绝；看 `RE_Kenshi_log.txt` 中 `prosthetic compatibility unknown` 与 `prosthetic idata keys:` 校准映射。
- 验证步骤：选中角色 → 截肢（状态应变断肢）→ 选型号安装（状态变义肢，外观更新）→ 恢复原生（状态回原形）。出错看 `KT_*.txt` 与日志。
