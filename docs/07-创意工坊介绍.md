# KenshiTrainer 创意工坊介绍文案 / Workshop Description

## 中文

**Kenshi 内置修改器（RE_Kenshi 插件）**

游戏内直接呼出的全能修改器，画面内嵌 Dear ImGui 界面，随游戏语言自动切换中/英文。

【功能一览】
★ 属性编辑 - 38 项属性读写 + 一键拉满（含 mod 属性）
★ 改名 / 金钱 - 即时修改，无需存档编辑
★ 物品生成 - 全物品库（含 mod 物品）搜索生成；武器支持制造商/模型/品质档联动；护甲六档品质；背包满了自动掉地上不丢失
★ 建筑放置验证开关 - 关掉"不能在这儿建"的一切限制，山坡、重叠、室内随便放（预览颜色仍会提示真实有效性）

【前置要求】
必须先安装 RE_Kenshi（见 GitHub: BFrizzleFoShizzle/RE_Kenshi），本插件是其 KenshiLib 插件。

【安装】
1. 安装 RE_Kenshi 并确认主菜单显示其版本号
2. 将 KenshiTrainer 文件夹放入 Kenshi/mods/
3. 启动器 Mods 页勾选 KenshiTrainer
4. 进游戏点左上角"修改器"按钮

【支持版本】Kenshi 1.0.65（Steam/GOG）+ RE_Kenshi v0.3.5+
【开源】GPL-3.0，源码与文档见 GitHub 仓库。

## English

**Kenshi In-game Trainer (RE_Kenshi plugin)**

All-in-one trainer with an embedded Dear ImGui overlay. The UI follows the game language (CN/EN automatically).

[Features]
* Stats editor - read/write 38 stats + max-all (modded stats included)
* Rename / money - instant edits, no save-game hacking
* Item spawner - full item database (mods included) with search; weapons with linked manufacturer/model/quality tiers; armour with six quality grades; full backpack drops overflow on the ground (never lost)
* Building placement bypass - turn off every "you can't build here" limit: slopes, overlaps, indoors - place anywhere (preview colour stays truthful)

[Requirements]
RE_Kenshi must be installed first (GitHub: BFrizzleFoShizzle/RE_Kenshi). This is a KenshiLib plugin.

[Install]
1. Install RE_Kenshi and confirm its version on the main menu
2. Drop the KenshiTrainer folder into Kenshi/mods/
3. Tick KenshiTrainer in the launcher Mods page
4. In game, click the "Trainer" button at the top-left

[Supported] Kenshi 1.0.65 (Steam/GOG) + RE_Kenshi v0.3.5+
[Open source] GPL-3.0 - sources and docs on GitHub.
