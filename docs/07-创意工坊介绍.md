# KenshiTrainer 创意工坊介绍文案 / Workshop Description（2026-09-24 版）

## 中文

**Kenshi 内置修改器（RE_Kenshi 插件）**

【前置要求 · 必读】
1. 必须先安装 **RE_Kenshi v0.3.5+**（本插件是它的 KenshiLib 插件，https://github.com/BFrizzleFoShizzle/RE_Kenshi ）。主菜单显示 RE_Kenshi 版本号 = 安装成功。
2. 支持 Kenshi 1.0.65（Steam/GOG）；1.0.68 请运行 RE_Kenshi 安装器完成兼容处理。
3. Windows 11 的 Smart App Control 和部分杀毒软件会静默拦截 DLL 注入，导致"找不到 DLL / 启用无反应"——请把 Kenshi 安装目录加入白名单。

【注意事项】
★ 所有修改即时生效，使用前建议先存档。
★ 截肢 / 义肢安装调用的是游戏自身的医疗系统，属真实机制操作，同样建议先存档。截肢并非安装必要条件，直接点击安装即可安装义肢。
★ 建筑放置绕过存在未修复的已知 bug，请酌情使用。
★ 与 Dust 画质增强 mod 及其他 RE_Kenshi 插件兼容，可正常双开同用。

【功能一览】
★ 属性编辑 — 38 项属性读写 + 一键拉满（含 mod 新增属性）
★ 改名 / 金钱 — 即时修改，无需编辑存档
★ 物品生成 — 全物品库搜索生成（含 mod 物品）；武器支持制造商 / 模型 / 品质档联动；护甲六档品质；背包满了自动掉地上不丢失
★ 医疗 — 截肢 / 义肢安装（全义肢库 + 品质档选择，可自动）/ 恢复原生肢体（满血恢复）；换装与卸下义肢自动退回背包
★ 建筑放置验证开关 — 关掉"不能在这儿建"的一切限制：山坡、重叠、室内随便放（预览颜色仍会提示真实有效性）

【界面】游戏内嵌 Dear ImGui 界面，点左上角"修改器"按钮呼出；界面语言随游戏语言自动切换中 / 英文。

【安装】
1. 安装 RE_Kenshi 并确认主菜单显示其版本号
2. 将 KenshiTrainer 文件夹放入 Kenshi/mods/
3. 启动器 Mods 页勾选 KenshiTrainer
4. 进游戏点左上角"修改器"按钮

【开源】GPL-3.0，源码与文档：https://github.com/casolopidia/KenshiTrainer

## English

**Kenshi In-game Trainer (RE_Kenshi plugin)**

[REQUIREMENTS - READ FIRST]
1. RE_Kenshi v0.3.5+ must be installed first (this is a KenshiLib plugin; https://github.com/BFrizzleFoShizzle/RE_Kenshi ). Its version number on the main menu means it works.
2. Supports Kenshi 1.0.65 (Steam/GOG); on 1.0.68 run the RE_Kenshi installer first for compatibility setup.
3. Windows 11 Smart App Control and some antivirus software silently block DLL injection ("DLL not found" / nothing happens) - whitelist the Kenshi install folder.

[NOTES]
* All changes apply instantly - save your game first.
* Amputation / prosthetic installation use the game's own medical system - again, save first.
* The building-placement bypass has known unfixed bugs - use at your own discretion.
* Compatible with the Dust graphics mod and other RE_Kenshi plugins - they can run together.

[FEATURES]
* Stats editor - read/write 38 stats + max-all (modded stats included)
* Rename / money - instant edits, no save-game hacking
* Item spawner - full item database (mods included) with search; weapons with linked manufacturer/model/quality tiers; armour with six quality grades; overflow drops on the ground, never lost
* Medical - amputate / install prosthetics (full limb database + quality tier selector, auto by default) / restore original limbs at full health; replaced or removed limbs return to your backpack
* Building placement bypass - turn off every "you can't build here" limit: slopes, overlaps, indoors (preview colour stays truthful)

[UI] Embedded Dear ImGui overlay - click the "Trainer" button at the top-left. UI language follows the game language (CN/EN).

[INSTALL]
1. Install RE_Kenshi and confirm its version on the main menu
2. Drop the KenshiTrainer folder into Kenshi/mods/
3. Tick KenshiTrainer in the launcher Mods page
4. In game, click the "Trainer" button at the top-left

[OPEN SOURCE] GPL-3.0 - sources and docs: https://github.com/casolopidia/KenshiTrainer
